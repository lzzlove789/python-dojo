# 第 14 关 · 排序与 key

> 场景：班主任要一份成绩排行榜（高分在前），还要一份按姓名排序的花名册。

## 概念讲解

两种排序：

| 写法 | 特点 |
| --- | --- |
| `sorted(seq)` | 返回**新列表**，原数据不变，任何可迭代对象都能用 |
| `lst.sort()` | **原地**排序，返回 `None`，只有列表有 |

两个常用参数：

- `reverse=True`：降序。
- `key=函数`：指定"按什么排"。每个元素先交给这个函数，拿返回值来比较。

`lambda` 是一种匿名小函数：`lambda s: s[1]` 等价于

```python
def get_score(s):
    return s[1]
```

排序是**稳定**的：比较结果相同的元素，保持它们原来的先后顺序。

## 命令教学

```python
people = [("Tom", 20), ("Amy", 18)]
print(sorted(people, key=lambda p: p[1]))   # 按年龄升序
```

## 本关任务

- [ ] `by_score`：成绩从高到低，`Tom` 和 `Bob` 同分，保持原顺序（Tom 在前）
- [ ] `by_name`：按姓名字母顺序
- [ ] 原来的 `students` 不能被改动（所以用 `sorted`，别用 `.sort()`）

## 小贴士

- 想按多个条件排，让 key 返回元组：`key=lambda s: (-s[1], s[0])`（分数降序、同分按名字）。
- 字符串按字典序比较，大写字母排在小写前面。
