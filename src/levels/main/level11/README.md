# 第 11 关 · 字典

> 场景：仓库用字典记录"商品名 → 库存"。今天进货、出库、下架一通操作，你要把账记对。

## 概念讲解

**字典（dict）** 存放"键 → 值"的对应关系，用花括号创建，按**键**而不是位置来取值：

```python
user = {"name": "Tom", "age": 18}
print(user["name"])
```

| 写法 | 作用 |
| --- | --- |
| `d[k] = v` | 新增或修改 |
| `d[k]` | 取值（键不存在会 `KeyError`） |
| `d.get(k, 默认)` | 安全取值 |
| `del d[k]` / `d.pop(k)` | 删除 |
| `k in d` | 判断键是否存在 |
| `d.items()` / `keys()` / `values()` | 遍历用 |

键必须是**不可变**类型（字符串、数字、元组），值可以是任何东西。

## 命令教学

```python
score = {"Tom": 88}
score["Amy"] = 95
score["Tom"] += 2
print(score)      # {'Tom': 90, 'Amy': 95}
```

## 本关任务

`stock` 起始是 `{"苹果": 5, "香蕉": 0}`：

- [ ] 新增 `"橙子": 8`
- [ ] `"苹果"` 进货 3 个
- [ ] 删除 `"香蕉"` 这个键
- [ ] `grape = ` 葡萄的库存，没记录则为 0（用 `get`）

## 小贴士

- 直接 `stock["葡萄"]` 取不存在的键会报 `KeyError`，不确定有没有时就用 `get`。
- Python 3.7+ 字典会保持插入顺序。
