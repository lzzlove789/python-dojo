# 第 2 关 · 变量与类型

> 场景：书店要上架一本新书，老板让你把商品信息存起来，并算出全部库存的总价值。

## 概念讲解

**变量**就是给数据贴的标签：`age = 18` 的意思是"让名字 `age` 指向数字 18"。Python 会自动判断类型，常见的有四种：

| 类型 | 名称 | 例子 |
| --- | --- | --- |
| `str` | 字符串 | `"Tom"` |
| `int` | 整数 | `18` |
| `float` | 浮点数（小数） | `60.5` |
| `bool` | 布尔值 | `True` / `False` |

变量名只能包含字母、数字、下划线，不能以数字开头；约定俗成用小写加下划线，比如 `on_sale`。

## 命令教学

```python
name = "Tom"
age = 18
print(type(age))      # <class 'int'>
print(age * 2)        # 36
```

## 小贴士

- `=` 是**赋值**，不是数学里的"等于"；判断相等要用 `==`（以后会学）。
- `True` 和 `False` 首字母必须大写。
