# 第 24 关 · 生成器与迭代器

> 场景：斐波那契数列要多少有多少，你不想一次把它们全放进内存——让生成器"用一个、算一个"。

## 概念讲解

`for x in 东西` 能工作，是因为"东西"是**可迭代对象**：它能产出一个**迭代器**，迭代器每次 `next()` 给出下一个值，没有了就抛出 `StopIteration`，`for` 会自动处理它。

自己实现迭代器很麻烦，所以有**生成器函数**：函数体里只要出现 `yield`，调用它就不会立刻执行，而是返回一个生成器对象；每次 `next()`，函数运行到下一个 `yield` 暂停，并记住所有局部变量。

```python
def count_up(n):
    i = 0
    while i < n:
        yield i        # 产出 i，然后暂停
        i += 1

for x in count_up(3):
    print(x)           # 0 1 2
```

好处：**惰性求值**——需要时才计算，占用内存很少，甚至可以表示"无穷序列"。

另一种写法是**生成器表达式**，和列表推导式很像，只是用圆括号：

```python
g = (x * x for x in range(1000000))   # 此刻几乎不占内存
next(g)                               # 0
```

注意：生成器**只能遍历一次**，耗尽后就空了。
