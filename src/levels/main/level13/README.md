# 第 13 关 · 列表推导式

> 场景：数据分析的同事看你用四行循环生成列表直摇头："这一行就能搞定。"

## 概念讲解

下面两段代码等价：

```python
# 传统写法
squares = []
for n in range(5):
    squares.append(n * n)

# 推导式
squares = [n * n for n in range(5)]
```

语法：

```
[ 表达式  for 变量 in 序列  if 条件 ]
```

- 先遍历序列，每个元素通过 `if` 筛选（可省略），再用"表达式"变换后放进新列表。
- 同样的思路还有字典推导 `{k: v for ...}` 和集合推导 `{x for ...}`。

## 命令教学

```python
print([i for i in range(10) if i % 2 == 0])   # [0, 2, 4, 6, 8]
```

## 本关任务

`nums` 是 1 到 10，`words` 是三个单词：

- [ ] `squares`：每个数的平方
- [ ] `even_sq`：只取偶数，然后平方 → `[4, 16, 36, 64, 100]`
- [ ] `lengths`：每个单词的长度
- [ ] 全部用推导式完成，不要写独立的 `for` 语句

## 小贴士

- 逻辑复杂（嵌套多层、多个条件）时，老老实实写循环，可读性更重要。
- `if ... else ...` 放在**表达式部分**：`["偶" if n % 2 == 0 else "奇" for n in nums]`。
