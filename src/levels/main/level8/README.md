# 第 8 关 · while 循环

> 场景：理财产品年化 10%，利息滚入本金。你想知道 1000 元要几年才能翻倍到 2000 元以上。

## 概念讲解

`for` 适合"循环次数已知"，而 `while` 适合"**只要条件成立就一直做**"：

```python
while 条件:
    循环体
```

每轮开始前先检查条件，成立才执行循环体。所以循环体里**必须有让条件最终变为假的动作**，否则就是死循环（本站运行超过 5 秒会被自动终止）。

两个控制语句：

- `break`：立刻跳出整个循环
- `continue`：跳过本轮剩下的代码，直接进入下一轮

## 命令教学

```python
n = 3
while n > 0:
    print(n)
    n -= 1
```

## 本关任务

`money` 初始 1000，`years` 初始 0：

- [ ] 用 `while money < 2000:` 循环，每年 `money *= 1.1`、`years += 1`
- [ ] 循环结束后 `years` 应为 8
- [ ] 用 `print` 输出 `years`
