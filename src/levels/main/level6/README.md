# 第 6 关 · 条件判断

> 场景：老师让你写个自动评级程序：90 分以上 A，80 以上 B，60 以上 C，其余 D。

## 概念讲解

程序需要"遇到不同情况做不同的事"，这就是 `if`：

```python
if 条件1:
    ...
elif 条件2:
    ...
else:
    ...
```

- 条件是结果为 `True` / `False` 的表达式：`==`（等于）、`!=`、`>`、`>=`、`<`、`<=`。
- 多个条件可以用 `and`、`or`、`not` 组合。
- **缩进决定归属**：冒号后面换行，缩进 4 个空格的代码才属于这个分支。
- 从上到下判断，**命中一个分支就不再往下看**，所以要把范围从严到宽排列。

## 命令教学

```python
score = 75
if score >= 60:
    print("及格")
else:
    print("不及格")
```

## 本关任务

本关用到了**函数**的雏形（第三章会详细学）：`def grade(score):` 定义一个叫 `grade` 的函数，`return` 把结果交出去。框架已经给好，你只需要补上里面的判断：

- [ ] `grade(95)` → `"A"`，`grade(90)` → `"A"`
- [ ] `grade(85)` → `"B"`
- [ ] `grade(60)` → `"C"`
- [ ] `grade(59)` → `"D"`
- [ ] 用 `elif` 完成多分支

## 小贴士

- 判断相等用 `==`（两个等号），一个 `=` 是赋值，写错会报语法错误。
- 注意边界：90 分算 A，所以用 `>=` 而不是 `>`。
