# 第 18 关 · *args 与 **kwargs

> 场景：同事想要一个"能接收任意个数字求和"的函数，还要一个"能接收任意字段生成描述"的函数。

## 概念讲解

有时你无法提前知道调用者会传几个参数。Python 提供两种"打包"：

| 写在**定义**里 | 作用 | 函数内得到 |
| --- | --- | --- |
| `*args` | 收集所有多余的**位置**参数 | 元组 |
| `**kwargs` | 收集所有多余的**关键字**参数 | 字典 |

`args`、`kwargs` 只是约定俗成的名字，真正起作用的是前面的 `*` 和 `**`。

同样的符号写在**调用**处，意思相反——"拆包"：

```python
nums = [1, 2, 3]
add(*nums)            # 等价于 add(1, 2, 3)
add(**{"a": 1})       # 等价于 add(a=1)
```

## 命令教学

```python
def show(*args, **kwargs):
    print(args, kwargs)

show(1, 2, x=3)    # (1, 2) {'x': 3}
```

## 本关任务

- [ ] `total(*nums)` 返回所有参数之和，不传参数返回 `0`
- [ ] `describe(**info)` 返回按键名排序的 `"k=v, k=v"`，如 `"age=18, name=Tom"`
- [ ] 用 `total(*args)` 得到 `result`
- [ ] 用 `describe(**opts)` 得到 `text`

## 小贴士

- 参数顺序：普通参数 → 默认参数 → `*args` → `**kwargs`。
- 写通用的包装器、转发函数时它们几乎必用，下下关的装饰器就会用到。
