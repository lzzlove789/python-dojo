# 第 12 关 · 集合与元组

> 场景：市场部导出的邮箱名单里有大量重复，还要找出两个活动的共同参与者。

## 概念讲解

**集合（set）**：不重复、无序。适合**去重**和**集合运算**。

```python
s = {1, 2, 2, 3}      # {1, 2, 3}
set([1, 1, 2])         # 把列表去重
```

| 运算 | 含义 |
| --- | --- |
| `a & b` | 交集（两边都有） |
| `a \| b` | 并集 |
| `a - b` | 差集（在 a 不在 b） |
| `x in s` | 是否存在，比列表快得多 |

注意：空集合要写 `set()`，`{}` 是空字典。

**元组（tuple）**：不可变的"只读列表"，用圆括号。函数返回多个值、字典的键常用它。可以**解包**：

```python
point = (3, 4)
x, y = point
```

## 命令教学

```python
a, b = {1, 2, 3}, {2, 3, 4}
print(a & b)    # {2, 3}
```

## 小贴士

- 集合无序，所以不能用下标访问，打印顺序也不固定。
- 需要去重又想保持顺序时，用 `dict.fromkeys(列表)`。
