# 第 9 关 · 列表

> 场景：你在做购物车功能：用户会不停地加商品、删商品，最后要知道还剩几件。

## 概念讲解

**列表（list）** 是有序、可修改的一组数据，用方括号创建，元素可以是任意类型：

```python
fruits = ["苹果", "香蕉"]
```

常用操作：

| 写法 | 作用 |
| --- | --- |
| `lst[0]` / `lst[-1]` | 取第一个 / 最后一个 |
| `lst.append(x)` | 末尾添加 |
| `lst.insert(i, x)` | 在位置 i 插入 |
| `lst.remove(x)` | 删除第一个等于 x 的元素 |
| `lst.pop()` | 取出并删除最后一个 |
| `lst.sort()` | 原地排序 |
| `len(lst)` | 元素个数 |
| `x in lst` | 是否包含 |

## 命令教学

```python
nums = [3, 1, 2]
nums.append(4)
print(nums)        # [3, 1, 2, 4]
```

## 本关任务

`cart` 起始是 `["苹果", "香蕉"]`：

- [ ] 末尾添加 `"橙子"`
- [ ] 在最前面插入 `"牛奶"`
- [ ] 删除 `"香蕉"`
- [ ] `count` 存放商品数量，最终 `cart` 为 `["牛奶", "苹果", "橙子"]`

## 小贴士

- `append`、`sort` 这类方法**直接修改原列表**，返回的是 `None`，别写成 `x = lst.sort()`。
- 删除不存在的元素会报 `ValueError`，可以先用 `in` 判断。
