# 第 3 关 · 运算符

> 场景：播放器显示时长需要"分:秒"格式，而后台只给了总秒数，你要把它拆开。

## 概念讲解

除了加减乘除，Python 还有几个很实用的运算符：

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `/` | 普通除法（永远得小数） | `7 / 2` | `3.5` |
| `//` | 整除（只要商） | `7 // 2` | `3` |
| `%` | 取余数 | `7 % 2` | `1` |
| `**` | 幂 | `2 ** 3` | `8` |

"整除 + 取余"是拆分单位的经典组合：总秒数 `//` 60 得到分钟，`%` 60 得到剩下的秒。

## 命令教学

```python
total = 125
print(total // 60)   # 2
print(total % 60)    # 5
```

## 本关任务

`total_seconds` 已经是 `1000`：
