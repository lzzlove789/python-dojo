# 第 17 关 · 函数与默认参数

> 场景：项目里到处复制粘贴同样的几行代码，组长说："把它们封装成函数！"

## 概念讲解

**函数**是起了名字的一段可复用代码：

```python
def 函数名(参数1, 参数2=默认值):
    ...
    return 结果
```

- `def` 定义，缩进的部分是函数体。
- `return` 把结果交还给调用者，并**立即结束函数**。没写 `return` 就返回 `None`。
- **默认参数**：调用时不传就用默认值；带默认值的参数必须放在后面。
- **关键字参数**：调用时写 `greet(greeting="嗨", name="Amy")`，可读性好，顺序也可随意。
- 返回多个值其实是返回一个元组，可以直接解包。

## 命令教学

```python
def add(a, b=10):
    return a + b

print(add(1))        # 11
print(add(1, 2))     # 3
```

## 本关任务

框架已经给好，补全两个函数：

- [ ] `greet(name, greeting="你好")` 返回 `"你好，Tom！"` 这样的字符串
- [ ] `bmi(weight, height)` 返回体重 ÷ 身高² 并保留 1 位小数
- [ ] 函数要 **return**，不要在里面 `print`

## 小贴士

- `print` 是"显示给人看"，`return` 才是"交给调用者用"，这是新手最常混淆的地方。
- 默认值不要用列表/字典这类可变对象（比如 `def f(x=[])`），那是经典陷阱。
