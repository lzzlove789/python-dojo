# 第 10 关 · 切片

> 场景：运营给了你 1 到 10 号的用户名单，要你分别取出前 3 个、后 3 个、偶数位和倒序名单。

## 概念讲解

**切片**用一对方括号取出序列的一段（列表、字符串、元组都适用）：

```
序列[起点:终点:步长]
```

- **起点包含，终点不包含**（和 `range` 一样）。
- 省略起点 = 从头；省略终点 = 到尾。
- 负数下标从末尾数：`-1` 是最后一个。
- 步长为负数时倒着取：`[::-1]` 就是整体反转。
- 切片得到的是**新列表**，原列表不变。

## 命令教学

```python
s = [10, 20, 30, 40, 50]
print(s[1:3])    # [20, 30]
print(s[-2:])    # [40, 50]
print(s[::2])    # [10, 30, 50]
```

## 本关任务

`nums` 是 1 到 10：

- [ ] `first3`：前 3 个 → `[1, 2, 3]`
- [ ] `last3`：最后 3 个 → `[8, 9, 10]`
- [ ] `evens`：偶数 → `[2, 4, 6, 8, 10]`（提示：从下标 1 开始，步长 2）
- [ ] `rev`：倒序
- [ ] 全部用切片，不要写 `for` 循环

## 小贴士

- 切片越界不会报错，只会取到能取的部分；而单个下标越界会 `IndexError`。
- 要记住：长度 = 终点 − 起点（步长为 1 时）。
