# 第 7 关 · for 循环

> 场景：财务让你算 1 到 100 的累加，以及其中所有偶数的和——别想着手算，让循环来干活。

## 概念讲解

`for` 循环让一段代码重复执行，每次取出一个元素：

```python
for 变量 in 可迭代对象:
    要重复的代码
```

最常配合 `range()` 使用：

| 写法 | 产生的数字 |
| --- | --- |
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |

**范围左闭右开**：包含起点，不包含终点。

## 命令教学

累加的经典套路——先放一个"累加器"，循环里不断加：

```python
total = 0
for i in range(1, 4):
    total += i      # 等价于 total = total + i
print(total)        # 6
```
