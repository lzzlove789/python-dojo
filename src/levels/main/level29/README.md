# 第 29 关 · 正则表达式

> 场景：客服系统里的聊天记录里混着手机号和邮箱，你要提取、校验，还要给手机号打码再展示。

## 概念讲解

**正则表达式**是描述"文本长什么样"的小语言。Python 用 `re` 模块，规则字符串前面加 `r`（原始字符串），这样反斜杠不会被转义：

```python
import re
re.findall(r"\d+", "a1b22c333")    # ['1', '22', '333']
```

常用元字符：

| 写法 | 含义 |
| --- | --- |
| `\d` / `\w` / `\s` | 数字 / 字母数字下划线 / 空白 |
| `.` | 任意一个字符（换行除外） |
| `+` / `*` / `?` | 1 次或多次 / 0 次或多次 / 0 或 1 次 |
| `{n}` / `{m,n}` | 恰好 n 次 / m 到 n 次 |
| `[abc]` | 括号里任意一个 |
| `(...)` | 分组，可用 `\1` 引用 |
| `^` / `$` | 开头 / 结尾 |

常用函数：

| 函数 | 作用 |
| --- | --- |
| `re.findall(p, s)` | 找出**所有**匹配，返回列表 |
| `re.search(p, s)` | 找**第一个**匹配，没有返回 `None` |
| `re.fullmatch(p, s)` | **整个字符串**都要匹配 |
| `re.sub(p, repl, s)` | 替换，`repl` 里可用 `\1` 引用分组 |

## 命令教学

```python
import re
print(re.sub(r"(\d{2})\d{2}", r"\1**", "1234"))    # 12**
```
