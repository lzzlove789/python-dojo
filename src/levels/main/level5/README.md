# 第 5 关 · input 与类型转换

> 场景：你在做一个小程序：问用户叫什么、多大，然后告诉他明年几岁。

## 概念讲解

`input("提示语")` 会暂停程序，等用户输入一行文字，并把它作为结果返回。

> 本站没有真正的键盘输入框：每一关会把预先准备好的输入**按顺序**喂给 `input()`。本关它依次读到 `小明` 和 `17`。

关键点：**`input()` 的结果永远是字符串**。`"17" + 1` 会报错，必须先转换：

| 函数 | 作用 |
| --- | --- |
| `int("17")` | 字符串 → 整数 |
| `float("3.5")` | 字符串 → 小数 |
| `str(17)` | 数字 → 字符串 |

## 命令教学

```python
n = int(input("数量："))
print(n * 2)
```

## 本关任务

- [ ] 第一次 `input()` 读取名字，存进 `name`
- [ ] 第二次 `input()` 读取年龄，**转成整数**存进 `age`
- [ ] 打印：`小明明年18岁`（用 f-string 和 `age + 1`）

## 小贴士

- 想一步完成读取和转换，可以直接嵌套：`age = int(input())`。
- 转换失败（比如 `int("abc")`）会抛出 `ValueError`，第四章会学怎么优雅处理。
