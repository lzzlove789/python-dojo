# 第 1 关 · 第一次打招呼

> 场景：新同事第一天入职，组长让你先在编辑器里跑通人生中第一个 Python 脚本。

## 概念讲解

Python 是一门**解释型**语言：你写一行，它执行一行，不用编译。最常用的"说话"方式就是 `print()`，它把括号里的内容显示在**输出**面板里。

- 文字叫**字符串**，必须放在引号里：`"Hello"` 或 `'Hello'` 都行。
- 数字和算式不需要引号，Python 会先计算再打印。
- 运算有优先级：先乘除、后加减，和数学一样。

## 命令教学

```python
print("你好，世界")   # 打印字符串
print(10 - 3)         # 打印 7
```

`#` 后面的内容是**注释**，Python 会忽略它，专门写给人看。

## 本关任务

- [ ] 用 `print` 输出一行：`Hello, Python!`
- [ ] 再用 `print` 输出 `1 + 2 * 3` 的计算结果（让 Python 来算，别手写 7）

写完点击编辑器上方的「运行」（或 `Ctrl + Enter`），右侧清单全部打勾就通关啦。

## 小贴士

- 括号、引号都要成对出现，而且必须是**英文**符号。
- 看到红色报错别慌，最后一行会告诉你哪里错了，先读它。
