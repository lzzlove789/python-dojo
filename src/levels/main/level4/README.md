# 第 4 关 · 字符串与 f-string

> 场景：用户在注册框里输入的昵称总带着多余空格，你要先清洗，再按统一格式展示。

## 概念讲解

字符串是一串字符，Python 给它内置了很多**方法**（用 `.` 调用的功能）：

| 写法 | 作用 | 例子 |
| --- | --- | --- |
| `s.strip()` | 去掉首尾空白 | `" a ".strip()` → `"a"` |
| `s.upper()` / `s.lower()` | 转大写 / 小写 | |
| `len(s)` | 字符个数 | `len("你好")` → `2` |
| `s[0]`、`s[-1]` | 取第一个 / 最后一个字符 | |
| `s[1:4]` | 切片，取下标 1 到 3 | |

**f-string** 是拼接文本最舒服的方式：在引号前加 `f`，用 `{}` 嵌入变量或表达式。

## 命令教学

```python
name = "Tom"
print(f"你好，{name}！")
print(f"2 + 3 = {2 + 3}")
```

注意：字符串方法**不会修改原字符串**，而是返回一个新的，所以要用变量接住结果。
